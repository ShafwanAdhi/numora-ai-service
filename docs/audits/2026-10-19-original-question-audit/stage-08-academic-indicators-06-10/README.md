Review baru mempertahankan identitas sumber per audit_id. Ada 55 entri dengan status berbeda dari review sementara; itu bukan seluruh ukuran perubahan bukti.

Sebanyak 21 entri proyeksi parser ditandai untuk pemeriksaan batas opsi/pembahasan pada [tahap 7](../stage-07-extraction-06-10/README.md). Paragraf asli, tabel, proyeksi parser dan hasil pembacaan akademik tersimpan terpisah. Pembahasan inline tidak otomatis dinyatakan hilang.

Hash seluruh 910 berkas sumber/bank/config/layanan tetap sama. Tidak ada koreksi sumber, perubahan bank/config, publikasi DB, API atau pemetaan runtime.
